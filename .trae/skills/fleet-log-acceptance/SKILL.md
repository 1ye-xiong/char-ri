# 车队日志策略题目验收检查

只读验收。以题面与 `docs/task-09/requirements.md` 为依据，不采信开发或测试 Agent 的自述结论。

## 输入

必须全部提供，缺一项对应检查记为 `未验证`：

- 待验收版本：提交哈希、PR 编号、目标部署地址与部署版本标识。
- `docs/task-09/requirements.md` 版本、`AGENTS.md` 版本与历史提交。
- 测试证据：测试命令与原始输出、`coverage.out`、可读覆盖率报告、`-race` 结果。
- Skill 证据：`.trae/skills/` 下两个 Skill 文件、`skill-usage.md` 与调用记录。
- 过程证据：会话导出、结构化事件清单、缺陷编号与复测记录、Git 提交与 PR 记录。

## 执行步骤

1. **版本核对**：确认验收的提交哈希 = PR 源提交 = 部署制品来源；不一致直接记 `不通过（版本不一致）`。
2. **逐条核对业务规则**：按 R-01～R-10 与需求文档 FR-01～FR-11，每条给出实现位置与可操作验证方式。
3. **走查五组演示场景**（必须实际操作，不得只看代码）：

| 场景 | 必须观察到的结果 |
| --- | --- |
| S1 正常推广 | 审批后 2 台试点成功；未推广前 3 台无配置；推广后 5 台逐车可核查；仅全部成功才可标记完成 |
| S2 审批与试点分支 | 退回可改重提；试点失败或超时后推广入口不可用；停止后未试点车无发布记录 |
| S3 恢复分支 | 停止页展示已发/未发且无"已撤销"表述；恢复版本高于原版本；已恢复与未确认分列 |
| S4 网络分支 | 离线车晚拉取、旧回执晚到、超时后成功、重复回执、跨车回执均不混淆生效值，且拒绝有记录 |
| S5 结果核查 | 同页出现成功、失败、未确认车辆；汇总与明细一致；总状态不掩盖未确认项 |

4. **通用要求核对**（题面第一部分）：
   - 页面可操作，能发起业务、查询结果、展示失败原因；不是静态页或写死结果。
   - 数据落库，重启服务后申请、活动、版本、回执、超时、拒绝记录仍可查。
   - 车辆与第三方为可控模拟，且能触发成功、失败、超时、重复通知。
   - 越权验证：申请人审批自己、A 车令牌上报 B 车回执、运营直接改回执，三者均被服务端拒绝。
   - 覆盖率：自编生产代码整体与各核心包均 ≥85%，未排除自编 repo/handler；`go vet`、`go test -race` 通过。
   - AGENTS.md 有历史版本、实际生效记录与对应任务；两个自编 Skill 各有用途/触发/输入/步骤/输出/失败处理/完成标准，并有"发现问题→修正→复测"的实际记录。
   - Git：MCP 建仓记录、`dev/09` 提交历史、提交格式 `[类型] [版本号] [编号] 中文`、feat/fix 的 meegle 核验输出、PR 与合并记录、主分支保护配置。
   - 部署：流水线含质量检查、覆盖率门禁、构建、部署、健康检查、业务冒烟；提供可访问地址与运行标识。
   - 视频与班级群提交：有讲解、有完整效果演示、有时间点目录；演示版本与验收版本一致。
5. **证据定位**：每条结论必须可回溯到 `文件:行`、命令输出、页面路径、提交哈希或视频时间点。
6. **输出报告**。

## 输出格式

```markdown
## 验收结论：通过 / 不通过 / 未验证

验收版本：<commit>  PR：<编号>  部署：<地址>

| 编号 | 要求 | 证据位置 | 结论 |
| --- | --- | --- | --- |
| R-01 | 审批人≠申请人 | service.go:88 / 实操截图 03:12 | 通过 |
| R-06 | 旧版本回执被拒 | 无对应记录 | 不通过 |

### 阻断项（必须修复）
1. <问题> → <复现步骤> → <期望结果>

### 未验证项
- <要求>：缺少 <证据>，需补充后重新验收
```

结论规则：

- 任一 R-01～R-10、任一组演示场景、覆盖率、部署或 Git 流程不通过 → 总体 `不通过`。
- 存在关键证据缺失但无确认缺陷 → 总体 `未验证`，不得写 `通过`。
- 只在全部条目为 `通过` 时才判定通过。

## 失败处理

- 证据不足：记 `未验证`，列出需补的具体材料，不猜测。
- 发现缺陷：登记缺陷编号，交回开发 Agent；修复后必须重跑受影响规则、场景与覆盖率，不接受"已口头修复"。
- 代码与文档矛盾：以题面为准，记录冲突并交学生确认；不得自行改动需求文档。
- 全程只读：不修改任何文件，不替开发补测试、补提交。

## 完成标准

- R-01～R-10、FR-01～FR-11、S1～S5 与通用要求全部有结论。
- 每条结论有可点击或可复现的证据位置。
- 阻断项可被第三人按复现步骤重现。
- 报告落到 `docs/task-09/acceptance-report.md`，与验收版本哈希绑定。
